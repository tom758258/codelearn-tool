# 13｜動態記憶體

> 配置、檢查與釋放。教材以繁體中文說明，C 關鍵字與程式名稱保留英文。

## 學習目標

- 說明 `malloc` 與 `free` 的用途。
- 在使用配置結果前檢查是否為 `NULL`。
- 知道配置大小、陣列界限與物件生命週期的關係。

## 核心觀念

動態記憶體（dynamic memory）可由程式在執行時要求。`malloc(bytes)` 回傳一塊適當大小的記憶體位置，無法配置時回傳 `NULL`。配置後的內容並未自動初始化，不可直接讀取未賦值的元素。

本章用 `malloc(count * sizeof *values)` 配置固定個數的整數，先檢查是否成功，再逐項初始化與加總。對於任意外部輸入的 `count`，實務上還需要檢查乘法溢位；本練習使用小型固定大小，讓焦點放在基本流程。

每次成功配置的記憶體都應有明確的擁有者與釋放時機。`free(values)` 之後不可再解參照舊指標或重複釋放；記憶體釋放後的內容不再屬於目前程式使用範圍。
