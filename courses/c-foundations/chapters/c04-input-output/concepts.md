# 04｜標準輸入與輸出

> 在啟動前提供輸入。教材以繁體中文說明，C 關鍵字與程式名稱保留英文。

## 學習目標

- 區分標準輸入（stdin）和標準輸出（stdout）。
- 使用 `scanf` 讀取兩個整數，並檢查是否成功。
- 理解本工具的輸入方式是執行前提供文字，而非執行中即時輸入。

## 核心觀念

`scanf("%d %d", &first, &second)` 嘗試從標準輸入讀取兩個整數。`&first` 和 `&second` 表示將數值寫入指定變數的位置；位址（address）與指標（pointer）會在後面的章節完整介紹。

**CodeLearn 操作重點：** 先展開 `Standard input`，填入 `12 8`（也可在末尾加換行），再按 `Run`。此工具會在啟動程式時一次送入文字並結束輸入，不提供執行中等待鍵盤輸入的互動終端機。

`scanf` 的回傳值是成功讀取的項目數。若不足兩個或格式不對，範例會顯示 `Invalid input` 並以非零狀態結束；這是程式有意處理錯誤的結果，不代表 CodeLearn 本身出錯。範例使用 `if` 檢查輸入，條件判斷將在下一章深入說明。

## 先預測，再實作

在 `Standard input` 輸入 `12 8` 再執行。接著只改輸入成 `7 5`，最後試試 `abc` 或只輸入 `12`；比較四次輸出，理解正常與錯誤路徑。
