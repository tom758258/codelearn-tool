# 09｜字元與字串｜結果與回顧

## 起始程式的參考輸出

```text
Length: 3
Equal: no
```

## 建議修改後的參考輸出

```text
Length: 3
Equal: yes
```

> 注意：上面是教材設計的參考結果，執行時需使用本章指定的起始資料或 `Standard input`。如果修改了其他程式碼，輸出也可能不同。

## 為什麼會得到這個結果？

`cat` 有三個可見字元，其陣列還需要結尾的 `\0`。只有在 `strcmp` 回傳 0 時才顯示 `yes`。不要為了增加長度直接寫超過陣列容量的字元。

## 常見錯誤

- 認為 `strlen` 會計入 `\0`。
- 把 `word == target` 當作 C 字串內容比較。
- 在沒有檢查容量時寫入過長字串。
