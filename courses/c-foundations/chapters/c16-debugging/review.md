## 為什麼會得到這個結果？

`2+4+6=12`，但程式每輪額外加 1，共三輪，所以錯誤結果為 15。這是有意提供的可編譯邏輯錯誤；不需要故意製造記憶體錯誤或無效指標來示範除錯。

## 常見錯誤

- 把「可以編譯」誤認成「邏輯一定正確」。
- 只看最後輸出而不追蹤第一個異常狀態。
- 把一般 Run 當成具有即時 Debug 狀態的模式。
