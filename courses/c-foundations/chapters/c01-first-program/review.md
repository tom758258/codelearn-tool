# 01｜第一個 C 程式｜結果與回顧

## 起始程式的參考輸出

```text
Hello, C!
```

## 建議修改後的參考輸出

```text
My first program
```

> 注意：上面是教材設計的參考結果，執行時需使用本章指定的起始資料或 `Standard input`。如果修改了其他程式碼，輸出也可能不同。

## 為什麼會得到這個結果？

雙引號中的文字就是要印出的字串；`\n` 使下一筆輸出從新的一行開始。修改程式後再次執行才會看到新結果；`return 0` 表示此範例正常結束。

## 常見錯誤

- 漏掉字串後面的分號 `;`，GCC 會給出編譯診斷。
- 把半形雙引號 `"` 改成全形引號，導致不是合法的 C 字串。
- 只改閱讀區的範例，而沒有開啟 Program Block。
