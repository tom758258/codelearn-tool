# 02｜變數與資料型態

> 儲存與顯示資料。教材以繁體中文說明，C 關鍵字與程式名稱保留英文。

## 學習目標

- 使用 `int`、`double`、`char` 宣告變數並給定初值。
- 理解字元常值與字串的差異。
- 依資料型態選擇正確的 `printf` 格式。

## 核心觀念

變數（variable）讓程式以名稱保存資料。宣告時會指定資料型態（type），例如 `int count = 3;` 是整數、`double price = 12.5;` 是浮點數、`char level = 'A';` 是單一字元。變數的值可以在後續敘述中改變。

`printf` 必須使用與參數型態一致的格式：`%d` 對應 `int`、`%f` 對應 `double`、`%c` 對應 `char`。`%.1f` 表示以一位小數顯示浮點數。字元使用單引號，如 `'A'`；雙引號如 `"A"` 表示字串，不能直接當作單一 `char`。

常值限定（`const`）可寫成 `const int days = 7;`，表示不能透過該名稱再指定新值。本章只需掌握基本宣告與輸出；整數與浮點運算的細節留在下一章。
