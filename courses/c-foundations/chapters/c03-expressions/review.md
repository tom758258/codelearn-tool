# 03｜運算子與型別轉換｜結果與回顧

## 起始程式的參考輸出

```text
Integer: 3
Floating: 3.5
```

## 建議修改後的參考輸出

```text
Integer: 4
Floating: 4.5
```

> 注意：上面是教材設計的參考結果，執行時需使用本章指定的起始資料或 `Standard input`。如果修改了其他程式碼，輸出也可能不同。

## 為什麼會得到這個結果？

在 `(double)a / b` 中，第一個運算元在除法開始前已成為浮點數；`a / b` 則在兩者皆為整數時截去小數部分。`%.1f` 控制的是輸出的顯示格式，不會改變除法本身的型別。

## 常見錯誤

- 以為把結果存到 `double` 就能補回整數除法的小數部分。
- 不分清 `(double)(a / b)` 與 `(double)a / b`。
- 把 `b` 改成 `0`；本課不可執行除以零的示例。
