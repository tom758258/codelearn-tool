# 03｜運算子與型別轉換

> 理解結果如何計算。教材以繁體中文說明，C 關鍵字與程式名稱保留英文。

## 學習目標

- 使用 `+`、`-`、`*`、`/` 及括號組合運算。
- 區分整數除法與浮點除法。
- 理解顯式型別轉換（cast）發生在運算之前或之後的差異。

## 核心觀念

運算式（expression）可以結合變數與運算子。乘除通常先於加減，括號可明確指定先後順序。當兩個 `int` 相除時，結果仍是整數，像 `7 / 2` 的結果是 `3`，不會自動變成 `3.5`。

若希望除法保留小數，可以在除法前把其中一個運算元轉為 `double`：`(double)a / b`。注意 `(double)(a / b)` 代表先做整數除法再轉型，已經失去的小數部分不會回來。

除數不能是零。比較運算（例如 `>`、`==`）與邏輯運算（例如 `&&`、`||`）也會產生真假判斷，本課先認識概念，下一章節會用條件分支實際運用。
