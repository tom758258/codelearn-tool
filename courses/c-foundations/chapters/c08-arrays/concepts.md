# 08｜陣列

> 管理一組數值。教材以繁體中文說明，C 關鍵字與程式名稱保留英文。

## 學習目標

- 宣告並存取一維陣列與索引。
- 利用迴圈走訪陣列、求和與找最大值。
- 認識二維陣列的列／欄存取與索引界限。

## 核心觀念

陣列（array）將相同型態的多個元素放在一起，索引從 0 開始。例如長度 4 的陣列可使用 `scores[0]` 到 `scores[3]`，`scores[4]` 不是有效元素。

常見做法是使用 `sizeof(scores) / sizeof(scores[0])` 計算陣列元素數量，再以 `size_t` 迴圈走訪。`size_t` 是用來表示大小／索引的無號整數型態，會在包含 `<stddef.h>` 等標頭時取得定義。

二維陣列可寫成 `int table[2][3]`，表示 2 列、每列 3 個整數，以 `table[row][column]` 存取。這章以一維陣列練習統計，二維陣列先掌握語法與界限。
