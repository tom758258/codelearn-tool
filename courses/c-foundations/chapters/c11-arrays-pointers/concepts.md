# 11｜陣列與指標的關係

> 把一組資料傳給函式。教材以繁體中文說明，C 關鍵字與程式名稱保留英文。

## 學習目標

- 理解函式接收陣列時需要額外的長度參數。
- 區分陣列物件與指向元素的指標。
- 使用索引方式遍歷函式接收的數值。

## 核心觀念

陣列傳入函式時，參數 `const int values[]` 會調整成指向元素的指標型態，因此函式無法用 `sizeof(values)` 計算原始陣列的元素數量。通常必須再傳入一個 `size_t count`。

陣列和指標有緊密關係，但並非任何情況都可以當成完全相同的東西。`values[i]` 以索引取用元素；對有效範圍內的元素，概念上可理解為由起始位置移動 `i` 個元素。

函式參數使用 `const int values[]`，表示函式不應透過此參數修改傳入的陣列。將資料長度與存取界限一起考慮，是寫出可重用函式的關鍵。
