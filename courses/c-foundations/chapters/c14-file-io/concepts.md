# 14｜檔案處理

> 在同次執行中寫入與讀取。教材以繁體中文說明，C 關鍵字與程式名稱保留英文。

## 學習目標

- 使用 `fopen`、`fputs`、`fgets` 與 `fclose` 完成基本檔案 I/O。
- 檢查開檔與讀檔失敗，避免假設每次 I/O 都成功。
- 理解 CodeLearn 執行時的暫存工作目錄不保證跨次 Run 持久化。

## 核心觀念

檔案輸入輸出（file I/O）讓程式讀寫檔案。`fopen("report.txt", "w")` 會嘗試開啟相對路徑檔案作為寫入目標；`fputs` 寫入內容，完成後用 `fclose` 關閉。接著可用 `"r"` 模式重新開啟並用 `fgets` 讀取。

此練習把「寫入、關閉、讀回、印到 stdout」放在**同一次 Run** 內完成。CodeLearn 的執行使用暫存工作目錄，不應期待上次 Run 寫入的 `report.txt` 在下一次還存在，也不會自動出現在學生編輯檔案清單中。

每次開檔都有可能失敗；成功檢查比假設路徑永遠可寫更可靠。此範例只使用合成資料，不操作使用者真實文件，也不要求特定 Windows/Linux 絕對路徑。

## 先預測，再實作

先執行程式觀察讀回的文字，再把 `"Stock: 4\n"` 改成 `"Stock: 8\n"` 重新 Run。不要在兩次 Run 之間依賴生成的檔案持續存在。

請按本章的 **Open exercise** 開啟練習，修改已提供的檔案，再使用 **Run** 觀察 **Program output**。Markdown 中的程式碼僅供閱讀，不會直接執行。`Run` 前請依現有流程保存程式碼；若缺少 GCC 可先閱讀課文，之後到 **Settings** 選擇通過驗證的 GCC。執行或除錯不會自動安裝工具鏈。

需要 Debug 的延伸練習請使用既有的 **Debug**、Breakpoint、Step 與 Variables；一般 Run 不會即時追蹤變數。
