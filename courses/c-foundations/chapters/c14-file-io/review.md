# 14｜檔案處理｜結果與回顧

## 起始程式的參考輸出

```text
Read back: Stock: 4
```

## 建議修改後的參考輸出

```text
Read back: Stock: 8
```

> 注意：上面是教材設計的參考結果，執行時需使用本章指定的起始資料或 `Standard input`。如果修改了其他程式碼，輸出也可能不同。

## 為什麼會得到這個結果？

寫檔後關閉可以完成資料提交，再以唯讀方式重新開啟同一相對檔案。讀到的字串中已有換行，`printf` 不必再添加第二個換行。

## 常見錯誤

- 以為 `"w"` 模式會保留舊檔內容；它會建立或截短檔案。
- 沒有檢查 `fopen` 的結果。
- 把 Run 的暫存產物當成長期保存的學生檔案。
