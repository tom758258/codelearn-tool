# 17｜綜合練習：商品清單

> 閱讀、修改並追蹤多檔 C 程式。教材以繁體中文說明，C 關鍵字與程式名稱保留英文。

## 學習目標

- 整合結構、陣列、迴圈、條件、函式及多檔程式。
- 讀懂簡單商品清單的輸出並修改來源資料。
- 使用既有 GDB 追蹤總額計算，完成可解釋的綜合練習。

## 核心觀念

綜合練習（capstone）把前面學到的多個觀念串起來，而不是要求記憶全新語法。`inventory.h` 定義商品結構與計算函式宣告，`inventory.c` 負責加總，`main.c` 建立兩筆合成商品資料並顯示明細。

為了讓初學者看得懂且不受浮點數誤差影響，單價使用整數分（cents）表示。商品清單使用固定測試資料，不依賴網路、真實使用者文件或跨次 Run 的暫存檔案。

先讀懂 `main.c`、`inventory.h` 和 `inventory.c` 的分工，再改變一筆商品數量，預測每行與總計會如何改變。若有 GDB，可在 `total_cents` 的迴圈設 Breakpoint，使用 Variables／Call Stack 追蹤加總。

## 先預測，再實作

先執行初始商品清單，預測總額。接著把 `Notebook` 的數量 2 改為 3，確認明細與總額都符合自己的計算。觀察函式跨 `.c` 檔案工作，不要新增或移除來源檔。

請按本章的 **Open exercise** 開啟練習，修改已提供的檔案，再使用 **Run** 觀察 **Program output**。Markdown 中的程式碼僅供閱讀，不會直接執行。`Run` 前請依現有流程保存程式碼；若缺少 GCC 可先閱讀課文，之後到 **Settings** 選擇通過驗證的 GCC。執行或除錯不會自動安裝工具鏈。

需要 Debug 的延伸練習請使用既有的 **Debug**、Breakpoint、Step 與 Variables；一般 Run 不會即時追蹤變數。
