# 17｜綜合練習：商品清單｜結果與回顧

## 起始程式的參考輸出

```text
Pencil x3: 45 cents
Notebook x2: 120 cents
Total: 165 cents
```

## 建議修改後的參考輸出

```text
Pencil x3: 45 cents
Notebook x3: 180 cents
Total: 225 cents
```

> 注意：上面是教材設計的參考結果，執行時需使用本章指定的起始資料或 `Standard input`。如果修改了其他程式碼，輸出也可能不同。

## 為什麼會得到這個結果？

鉛筆 3 件、每件 15 分，共 45 分；筆記本 2 件、每件 60 分，共 120 分，合計 165 分。數量改成 3 時，第二項變成 180 分、總額 225 分。這個程式仍使用原有 Course Program Block 的獨立 Build／Run／Debug，不需要進階專案系統。

## 常見錯誤

- 忘記修改資料後重新執行，仍把舊輸出當成新結果。
- 把單價與數量混用，導致總額不正確。
- 把 `.h` 的宣告誤認為已包含 `.c` 的實作，或漏看跨檔呼叫。
