# 06｜迴圈

> 重複執行與終止條件。教材以繁體中文說明，C 關鍵字與程式名稱保留英文。

## 學習目標

- 使用 `for` 和 `while` 控制重複次數。
- 知道 `do while` 至少執行一次，並認識 `break`、`continue`。
- 辨認迴圈初始值、條件與更新的關係。

## 核心觀念

迴圈（loop）用來重複處理相似資料。`for` 通常把初始化、持續條件與更新寫在同一行；`while` 先檢查條件再執行內容；`do while` 則先執行一次再檢查。

範例使用 `for (int i = 1; i <= limit; ++i)`，把 1 到 `limit` 的整數加總。每一輪都必須朝終止條件前進，否則可能出現不結束的程式。

`break` 用來提前離開迴圈；`continue` 跳過本輪剩餘敘述，進到下一輪。先熟悉基本終止條件，再研究這兩者對流程的影響。

## 先預測，再實作

先預測 `limit = 5` 的總和並執行，接著改成 3 和 6；觀察 `i` 的變化。可以在加總的程式行設斷點，逐次執行觀察 `sum`（選用 GDB）。
