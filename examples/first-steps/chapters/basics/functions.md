## Follow a function call

The next exercise has three files. `sum.h` declares a function, `sum.c` defines it, and `main.c` calls it.

下一個練習包含三個檔案：`sum.h` 宣告函式，`sum.c` 定義函式，`main.c` 呼叫它。

1. Open the exercise and choose **Debug**.
2. Add a breakpoint beside the call to `sum` in `main.c`.
3. Choose **Continue**, then **Step into**.
4. Inspect **Variables** and **Call stack** while the program is paused.

Switching to `sum.h` does not change which C files are compiled.

1. 開啟練習並選擇 **Debug**。
2. 在 `main.c` 呼叫 `sum` 的行號旁新增斷點。
3. 選擇 **Continue**，再選 **Step into**。
4. 程式暫停時查看 **Variables** 與 **Call stack**。

切換至 `sum.h` 不會改變要編譯的 C 檔案。
